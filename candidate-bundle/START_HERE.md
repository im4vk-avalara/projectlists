# Infra Security Practical Round

This is a 60-minute, hands-on infrastructure security exercise using a
synthetic local environment.

Please join five minutes early for a setup check. Downloading, extracting, and
starting the supplied lab are not evaluated. The assessment clock starts after
screen sharing works and the starter verifier identifies the
`approved-consumer` entry point and prints `PASS`.

## Format

| Time | Activity |
|---|---|
| 5 min | Scenario framing and clarifying questions |
| 40 min | Investigate, demonstrate impact, remediate, and verify |
| 10 min | Production-design follow-up and changing constraint |
| 5 min | Candidate questions |

You will receive a password-protected bundle containing a small configuration,
evidence set, and local macOS lab at the start of the round. No access to a
real production or cloud account is required.

You may use your editor, terminal, documentation, internet access, and an AI
assistant. We evaluate how you reason from evidence, verify claims, prioritize
risk, and defend your implementation. This is not a cloud-product trivia test,
and you may map your production recommendation to any infrastructure stack you
know well.

Please share your screen, think aloud, state assumptions, and ask clarifying
questions. You should expect to:

- triage an existing security assessment;
- demonstrate whether a reported boundary is enforceable;
- make a small configuration or code change;
- run a regression check;
- explain rollout, monitoring, and rollback.

Bring a Mac with a working editor, terminal, and Python 3 environment. The
exercise supports Apple Silicon and Intel Macs.
