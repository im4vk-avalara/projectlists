# Raylib Template

## Quick Start

```console
$ cc -o nob nob.c
$ ./nob
$ ./main
```


New Controls:
G - Toggle glyph grid viewer (shows all 95 characters from the TTF)
Mouse hover - Highlights glyph and shows detailed info panel (codepoint, metrics, atlas position)
Mouse wheel - Scroll through glyphs
+/- - Resize glyph cells (32-128px)
TAB - View raw atlas texture
UP/DOWN - Adjust font size in demo mode
